# Changelog

## [Unreleased]

### Added

- Default to `_home` note if it exists on app launch

## [1.1.0]

### Added

- Markdown syntax highlighting
- Markdown actions; push `alt` + `enter`, or `alt` + `click` to:
  - Toggle a checkbox `- [ ] my list item`
  - Visit an external link `[Google](https://google.com)`
  - Navigate between notes `[Todo](todo)`
- Ability to resize the file list area of the window

## [1.0.2] - 2020-05-27

### Changed

- After searching for files, when focusing on editor, reset file list to all files
- (macOS) When closing the window, quit the application

## [1.0.0] - 2020-05-22

- Initial release of nimblenote
- Prior releases before this were when nimblenote was known as Noted
